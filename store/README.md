# Store-Unterlagen – Znuny Helper

Alles, was für die Veröffentlichung im Chrome Web Store und bei Firefox Add-ons (AMO) gebraucht wird.

| Datei | Zweck |
| --- | --- |
| `listing.md` | Name, Kurz- und Langbeschreibung, Kategorie, Berechtigungsbegründungen |
| `datenschutz.md` | Datenschutzerklärung (keine Datenerhebung) |
| `checkliste.md` | Was beim Hochladen eingetragen und geprüft werden muss |
| `screenshots/` | Bilder 1280 × 800 für die Store-Seite |

## Upload-Dateien

| Store | Datei |
| --- | --- |
| Chrome Web Store | `znuny-helper-extension.zip` |
| Firefox Add-ons | `znuny-helper-extension-firefox.zip` (oder `.xpi`, identisch) |

## Wichtig vor dem Veröffentlichen

Die Erweiterung läuft **ausschließlich** auf `https://otrs.staff.hsrw` (Znuny der Hochschule Rhein-Waal). Das steht in der Beschreibung und in der Datenschutzerklärung – sonst wirkt die Veröffentlichung wie eine allgemeine Erweiterung, die auf anderen Instanzen nichts tut.
